# Bookmark Manager

A simple MERN Stack application that allows users to save, manage, filter, and delete useful website bookmarks.

## Technologies Used

- MongoDB
- Express.js
- React.js
- Node.js
- Axios

## Features

- Add new bookmarks
- Display all bookmarks
- Mark bookmarks as favorites
- Filter bookmarks by tag
- Delete bookmarks

## Installation & Setup

### Backend Setup

1. Open the backend folder.
2. Install dependencies:

   npm install

3. Create a `.env` file and add your MongoDB connection URI:

   MONGO_URI=your_mongodb_connection_string

4. Start the backend:

   npm run dev

### Frontend Setup

1. Open another terminal.
2. Navigate to the frontend folder.
3. Install dependencies:

   npm install

4. Start React:

   npm run dev

## Usage

Open the frontend URL shown in the terminal and start managing your bookmarks.
